# Booking illustrations

Created with the built-in Imagegen tool for the staged MyDhobi booking flow.
These are transparent 3D vector-style raster illustrations, not editable SVG paths.

Original PNGs and the exact generation prompts are saved in this folder.
The app uses 360 × 360 WebP exports in `apps/web/public/booking/3d-v1/`.
General Booking uses a shirt on a hanger; Package Booking uses a laundry basket on a weighing scale.
