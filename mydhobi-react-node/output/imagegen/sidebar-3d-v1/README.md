# Sidebar icons

Created with the built-in Imagegen tool for MyDhobi Admin. Each PNG is an original generated image with transparency. These are 3D vector-style raster illustrations, not SVG paths.

The app uses small 96 × 96 WebP exports from `apps/web/public/sidebar/3d-v1/`, displayed at 28 px in the full sidebar and 26 px in the compact sidebar. The original PNGs are retained here. Exporting to WebP preserves transparency and keeps navigation artwork small.

`prompts.json` contains the full prompt for each icon. Menu settings reuses the settings icon. Existing action controls and the MyDhobi mark keep their Lucide icons.
